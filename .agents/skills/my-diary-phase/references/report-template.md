# 最終報告テンプレート

事実だけを記載する。該当しない章は「対象外」、実行できなかった章は「未実施」と理由を記載し、成功したように表現しない。

## 1. 必須入力

個別プロンプトから受け取ったPhase名、目的、基準HEAD、対象・対象外、DB変更、migration作成、リモート操作、ブラウザ検証、commit、push、固有停止条件。不足があれば、その項目と作業範囲への影響。

## 2. 作業前のGit・環境状態

branch、ローカルHEAD、ローカルの比較先、実リモートの確認結果、ahead/behind、ワークツリー、必要な環境の状態。厳密な読み取り専用Phaseでは、ローカルの`origin/main`が古い可能性と実リモート未確認の理由を区別する。

## 3. 適用した安全ゲート

Git基準確認、差分許可リスト、秘密情報非参照、DB・テストデータ・プロセス・リモート操作の制限、Phase固有の許可確認。

## 4. 停止条件

発動しなかった条件、個別操作で発動した条件、実行を中止した操作と理由。Phase全体の停止と個別操作の停止を区別する。

## 5. 実施内容

Phaseの目的、実装・調査内容、対象範囲。

## 6. 認証・権限制御

認証、RLS、visibility、ユーザーIDの信頼境界。対象外の場合はその理由。

## 7. バリデーション

入力、境界値、エラー処理、二重送信等の確認結果。

## 8. 変更ファイル

追加・変更・削除ファイルと各目的。

## 9. pgTAP

実行コマンド、対象、結果。対象外または未実施理由。

## 10. lint・typecheck・build

各コマンド、結果、警告・失敗。未実施理由。

## 11. ブラウザ検証

対象画面、操作、ブラウザ、自動・手動の別、結果。対象外または未実施理由。

## 12. レスポンシブ

確認した画面幅、横スクロール、長文・改行・連続半角文字列の結果。

## 13. アクセシビリティ・console

label、フォーカス、ARIA、キーボード、console warning/error、hydration error。

## 14. migration・DB差分

migration履歴、作成・適用の有無、linked schema diff、DB変更の有無。確認不能なら理由。

## 15. 発見した問題と修正

問題、原因、修正、再検証。なければ「なし」。

## 16. 未実施・手動確認

未実施項目、理由、残るリスク、手動確認手順。

## 17. 読み取り専用・変更なしの確認

読み取り専用Phaseでは、ファイル、DB、テストデータ、プロセスを変更していないことと、Git stage、commit、pushを行っていないことを個別に記載する。該当しない場合は「対象外」、確認できない場合は理由を記載する。

## 18. Git diff

`git diff --check`、status、diff要約、Phase範囲外の差分の有無。

## 19. commit・push状態

commitの有無とhash、pushの有無と送信先。行っていない場合は「commit未実施」「push未実施」と明記する。

## 20. 既知の制約

現時点で残る制約、環境依存、未対応範囲。

## 21. 次に推奨する作業

次の安全な小単位、必要な許可、手動確認。
